# 财智通

数据只在你电脑里的本地记账软件。macOS 先行，之后 Windows。

- 下载：见右侧 [Releases](../../releases)；每个安装包的 SHA256 写在版本说明里。
- 官网：https://aigoldlab.com/caizhitong
- 更新日志：https://aigoldlab.com/caizhitong/changelog

## 隐私承诺

- 本地存储：账本是你电脑上的明文 SQLite 文件，随时可导出 CSV。
- 零后台请求：软件本身不联网，授权码离线校验；欢迎用防火墙监控。
- 没有账号、没有埋点、没有广告。

## Agent 接口

内置给本地 AI Agent 读写账本的工具，参数、可读写字段和写前自动备份规则将在首个公开版本发布时在此披露。
先看：https://aigoldlab.com/caizhitong/agent
